## 1. 产品概述

### 1.1 产品定义

**RustVerse** 是一款跨平台桌面应用，作为 `rustup` 的图形化管理前端，帮助 Rust 开发者可视化管理工具链、组件、编译目标、Cargo 插件、镜像源和环境变量。

### 1.2 目标用户

- Rust 初学者：需要简化工具链安装和管理流程
- Rust 开发者：需要高效管理多工具链、多编译目标
- 运维工程师：需要管理环境变量持久化配置
- 国内开发者：需要通过镜像源加速 Rust 工具链下载

### 1.3 核心价值

- **可视化 rustup 操作**：告别命令行，所有 rustup 功能图形化
- **降低入门门槛**：自动检测环境、引导安装
- **多版本管理**：历史版本浏览、多工具链切换
- **镜像加速**：集成 crm（China Rust Mirror），一键切换镜像源

## 4. 用户场景

### 场景 1：新手安装 Rust 环境

1. 用户首次启动 RustVerse
2. 系统显示欢迎页，提示需要安装 rustup
3. 用户点击"安装 Rust 环境"
4. 系统下载 rustup 安装器并执行安装
5. 安装进度实时显示在控制台
6. 安装完成后，自动刷新环境检测
7. 仪表盘显示 rustup 和 cargo 版本信息
8. 系统发出安装成功通知

### 场景 2：开发者切换工具链版本

1. 用户进入工具链页面
2. 系统展示已安装的工具链列表（含默认/活跃标记）
3. 用户点击"安装新工具链"，选择频道（stable/beta/nightly）
4. 可选指定日期版本
5. 系统开始安装并实时显示进度
6. 安装完成后发送通知
7. 用户可在列表中点击"设为默认"切换默认工具链

### 场景 3：更新工具链

1. 用户进入更新页面
2. 系统自动执行 `rustup check`，显示各工具链更新状态
3. 显示哪些工具链需要更新及版本差异
4. 用户点击"全部更新"
5. 系统依次更新所有工具链，实时显示进度
6. 更新完成后发送通知

### 场景 4：管理 Cargo 插件

1. 用户进入 Cargo 插件页面
2. 系统显示已安装插件列表
3. 用户可在搜索框中输入插件名搜索
4. 点击"安装"安装新插件
5. 点击"移除"卸载不需要的插件
6. 操作完成后发送通知

### 场景 5：设置镜像加速

1. 用户进入镜像源页面
2. 系统检测 crm 是否已安装
3. 如未安装，点击"安装 crm"
4. 系统显示可用镜像源列表（含当前默认镜像）
5. 用户点击"测试延迟"，查看各镜像响应时间
6. 用户选择最佳镜像，点击"切换"
7. 后续 rustup/cargo 下载自动使用新镜像

### 场景 6：配置环境变量

1. 用户进入环境变量页面
2. 系统按分类展示 Rust 相关环境变量
3. 用户修改/添加环境变量值
4. 可选择将变量持久化到系统（Windows 注册表或 Unix shell 配置文件）
5. 设置 RUST_LOG 时自动同步后端日志级别

### 场景 7：查看通知历史

1. 用户点击 TopBar 通知铃铛图标
2. 系统展示通知中心页面
3. 所有通知按时间倒序排列
4. 用户可按分类筛选（安装/更新/操作）
5. 支持搜索通知内容
6. 支持标记已读/未读
7. 支持删除单个或全部通知
8. 支持分页加载更多通知

### 场景 8：配置用户偏好

1. 用户进入设置页面
2. 切换应用主题：自动/深色/浅色
3. 配置代理模式：不使用/系统代理/手动代理
4. 开启/关闭各类通知
5. 设置自动清理过期通知时间
6. 每项设置独立保存并显示反馈状态

## 6. 数据管理

### 6.1 数据库

- **类型**: 嵌入式 redb（纯 Rust key-value 数据库）
- **位置**: `<安装目录>/data/config.redb`
- **迁移**: 自动从旧 `config.toml` 迁移到 redb

### 6.2 数据表

| 表名 | 用途 |
|------|------|
| `config_simple` | 简单 key-value 配置（二进制路径、超时、事件名、解析标记等） |
| `config_plugins` | 官方 Cargo 插件白名单 |
| `config_env_vars` | 环境变量元数据 |
| `config_settings` | 用户设置 JSON |
| `notifications` | 通知记录 |

### 6.3 用户设置项

{
  "minimize_to_tray": false,

    "default_priority": "medium",
    "do_not_disturb": false,
    "sound_enabled": false,

  },
