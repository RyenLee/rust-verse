v1.4.3 2026-06-05 最新 Latest
改进 Improved
  • Iconify 图标按需加载 — 将全量 @iconify-json/mdi 包（3MB，7000+ 图标）替换为构建时提取的最小集（29KB，97 个图标），新增 extract-used-icons.cjs 脚本自动提取源码中实际使用的图标
  • Iconify icons on-demand loading — Replaced full @iconify-json/mdi bundle (3MB, 7000+ icons) with build-time extracted minimal set (29KB, 97 icons)
  • Vue DevTools 条件加载 — DevTools 仅在开发模式且非 Tauri Debug 模式下加载，生产构建节省 10-20MB 内存
  • Vue DevTools conditional loading — DevTools only loads in development mode, saving 10-20MB in production builds
  • 查询缓存过期清理 — 添加后台清理线程定期移除过期缓存条目，防止内存无限增长
  • Query cache expiry cleanup — Added background cleanup thread to periodically remove expired cache entries
  • 历史版本列表优化 — 使用 shallowRef 替代 ref 减少响应式开销，限制列表长度防止内存过度占用
  • History version list optimization — Uses shallowRef to reduce Proxy tracking overhead, limits list length
  • keep-alive 策略优化 — 仅缓存高频页面，减少非活跃页面组件的内存占用
  • keep-alive strategy optimization — Only caches high-frequency pages to reduce memory from inactive components
修复 Fixed
  • 通知清理线程泄漏 — 为通知清理后台线程添加优雅退出机制，防止应用关闭时线程资源泄漏
  • Notification cleanup thread leak — Added graceful exit mechanism for the notification cleanup background thread
